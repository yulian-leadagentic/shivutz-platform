# §1 · צורה

**`scripts/smoke_test.py`** — Python, כמו `run_migrations.py`. הוא צריך **גם HTTP וגם DB**, ובדיוק לכן shell לא מספיק.

> ⚠️ **קיים כבר `scripts/smoke-test.sh`.** **קרא אותו קודם.** אם הוא מכסה משהו — אל תשכפל. **דווח אם הוא מיותר, אל תמחק אותו בלי אישור.**

```
python scripts/smoke_test.py --base-url https://<staging> [--seed-report]
```

- **`exit 0`** — הכל עבר · **`exit 1`** — כשל אחד או יותר
- **פלט: טבלה** `בדיקה | צפוי | בפועל | PASS/FAIL`. כישלון מדפיס את הגוף המלא של התשובה
- **`--seed-report`** — מצב דיווח בלבד על דאטת הזרע (§4). **לא מכשיל**

## 🔴 1.1 · הגנת פרודקשן

```
אם base-url מכיל את דומיין הפרודקשן  ⇒  refuse + exit 2
```

**ללא דגל עקיפה.** הסקריפט מנסה כניסות ומנסה חשיפות — **הוא לא ירוץ מול משתמשים אמיתיים.**

## 1.2 · אימות

`MASTER_OTP` עובד בסטייג'ינג (`CLAUDE.md`). הסקריפט מתחבר כארבע ישויות זרע:

| | |
|---|---|
| `CONTRACTOR_APPROVED_PHONE` | קבלן `approved` + מנוי פעיל |
| `CONTRACTOR_PENDING_PHONE` | קבלן `pending` |

- **טלפונים מ-`ENV`.** לא בקוד
- 🔴 **ארבעתם חייבים להיות `is_seed = TRUE`. הסקריפט מאמת את זה ב-DB ונכשל אם לא.**
- 🔴 **לעולם אל תדפיס טוקן, OTP או סיסמה.** גם לא בכישלון
- **אם ישות חסרה בסטייג'ינג — צור אותה בסידר וסמן `is_seed`.** דווח מה יצרת

# §2 · הבדיקות

## 2.1 · אנונימי — מה חסום

| # | בקשה | צפוי |
|---|---|---|
| A1 | `POST /api/search` | **401** |
| A2 | `GET /api/ads/public/{id}` | **חסום** |
| A3 | `GET /api/ads/{id}/contact-reveal` | **401** |
| A4 | URL של מסמך שהועלה | **401/403** |
| A5 | חיפוש קולי | **חסום** |

## 2.2 · אנונימי — מה **חייב** להישאר פתוח

**הכיוון ההפוך, וחשוב לא פחות.** L2 סגר את החיפוש; **אסור שהוא סגר את זה:**

| # | | צפוי |
|---|---|---|
| B1 | `/terms` · `/privacy` · `/accessibility` | **200** |
| B2 | `GET /legal/{slug}` × 3 | **200** |
| B3 | דף הבית | **200** |

🔴 **דף תנאי שימוש שדורש התחברות הוא באג משפטי.** הבדיקה הזאת שווה יותר ממה שהיא נראית.

## 2.3 · בידוד בין ישויות — L1

קבלן A מנסה על קבלן B, וכל אחד מהחמישה:

```
GET /organizations/contractors/{B}
GET /organizations/contractors/{B}/users          ← כאן הטלפונים
GET /organizations/corporations/{X}
GET /organizations/corporations/{X}/users
GET /organizations/corporations/{X}/documents
```

- **כולם → 403**
- **ועל הישות של עצמו → 200.** בלי זה ייתכן ששברנו הכל ולא נדע

## 2.4 · 🔴 אישור ומכסה — הבדיקה החשובה ביותר

```
1  DB:   SELECT COUNT(*) FROM contact_reveals           → before
2  HTTP: קבלן pending → POST /ads/{id}/contact-reveal   → 403 entity_not_approved
3  DB:   SELECT COUNT(*) FROM contact_reveals           → after
4  ASSERT before == after
```

**אותה בדיקה בדיוק על מסך ההיסטוריה:**
```
before → GET /contractor/reveals → after → ASSERT before == after
```

> **למה זו הבדיקה החשובה:** ניסיון חסום או צפייה בהיסטוריה **שסופרים במכסה** הם באג ששורף כסף של לקוח, **ואף אחד לא ישים לב אליו עד שלקוח יתלונן.** זו בדיוק הבדיקה שאדם עייף מדלג עליה במעבר ידני.

## 2.5 · דליפות בתשובות — grep על ה-JSON

| # | | חייב **לא** להכיל |
|---|---|---|
| D1 | תשובת `/search` (קבלן מאושר) | `corp_name` · `company_name` · `phone` · `email` |
| D2 | תשובת `/search` | **תווית תג אמון כן קיימת** (`trust_level`) |
| D3 | `/ads/mine/reveals` (תאגיד) | **כל שדה מזהה של קבלן** |
| D4 | `/legal/{slug}` | `<script` · `onerror=` · `javascript:` |

**D3 — השוואה לרשימה סגורה של שדות מותרים.** *"לא מצאתי `contractor_id`"* אינו מספיק; **שדה חדש שיתווסף מחר יעבור.**

## 2.6 · נראות לתאגיד — H12

- תאגיד מחפש עובדים → **רק המודעות שלו.** השווה `owner_entity_id`
- תאגיד מחפש דיור → **רואה גם של אחרים**
- תאגיד → `contact-reveal` על מודעת עובדים זרה → **403**, **והמכסה לא זזה**

## 2.7 · כסף

- `SELECT COUNT(*) FROM payment_events WHERE is_fake = FALSE` → **חייב להיות 0 בסטייג'ינג.** אם לא — **FAIL רועש**
- אם הריצה יצרה שורות: **כולן `is_fake = TRUE`**
