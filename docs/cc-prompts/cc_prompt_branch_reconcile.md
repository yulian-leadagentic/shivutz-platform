`git status` לא אמין בגלל CRLF (פריט B2) — **אל תסיק ממנו מסקנות.** השתמש ב-`git log` ו-`git diff --stat` בין ענפים.

# שלב 1 · מיפוי — קריאה בלבד

הרץ ודווח את הפלט **המלא**, בלי לסכם ובלי לפרש:

```bash
git rev-parse --abbrev-ref HEAD
git branch -vv --all
git remote -v

# מה יש בכל ענף שאין באחר
git log --oneline --no-merges staging..pivot/v2
git log --oneline --no-merges pivot/v2..staging
git log --oneline --no-merges main..staging
git log --oneline --no-merges main..pivot/v2

# מה נפרד, ומאיפה
git merge-base staging pivot/v2
git log --oneline -1 $(git merge-base staging pivot/v2)

# היקף ההבדל, בלי רעש סופי-שורה
git diff -w --stat staging pivot/v2

# מיגרציות — הסיכון הגבוה ביותר
git ls-tree --name-only staging  db/migrations/ | sort > /tmp/m_staging.txt
git ls-tree --name-only pivot/v2 db/migrations/ | sort > /tmp/m_pivot.txt
diff /tmp/m_staging.txt /tmp/m_pivot.txt

git worktree list
```

## שאלות שהדוח חייב לענות עליהן במפורש

1. **כמה קומיטים ייחודיים בכל כיוון**, ומה הם — בשורה אחת לכל אחד
2. **האם יש התנגשות מספרי מיגרציה** — אותו מספר, שני קבצים שונים. **זה הסיכון הגבוה ביותר וצריך תשובה חד-משמעית**
3. **אילו קבצים שונים בשני הענפים** לפי `-w` (בלי CRLF) — רשימה, לא מספר
4. **על איזה ענף יושבים הקומיטים שסקרנו בשבועיים האחרונים?** בדוק במפורש: `701924c` `fd9535d` `0262d2e` `dbbcbd8` `93dcd5a` `ed15382` `b384440` `0890b9a`. לכל אחד — באיזה ענפים הוא נמצא (`git branch --contains <sha>`)
5. **לאן Railway פורס בפועל מכל ענף?** מקובץ תצורה או ממסמכי `docs/ENVIRONMENTS.md` — ואם המסמך סותר את המציאות, אמור זאת
6. **מה מצב ה-worktrees**, ויש בהם עבודה שלא קומטה?

**עצור כאן. דווח. אל תמשיך בלי אישור מפורש מ-Yulian.**

# שלב 2 · האיחוד — רק אחרי אישור

לא כותב כאן תוכנית איחוד, כי היא תלויה לגמרי בתשובות. **אחרי הדוח נחליט יחד**, ואז תקבל פרומט נפרד.

**מה שכן קבוע מראש, בלי קשר לתוצאה:**

- `git tag pre-merge-staging` על **שני** הענפים לפני כל פעולה
- **אין `git add -A`.** קבצים בשם מפורש בלבד — CRLF יגרור אלפי שינויי-פאנטום
- **אם יש התנגשות מספרי מיגרציה — עוצרים ומדווחים.** לא ממספרים מחדש על דעת עצמך
- `main` לא נגעים בו בשום שלב
