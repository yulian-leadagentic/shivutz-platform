# §2 · Backend

## 2.1 · השדות בתוצאות החיפוש

`_serialize_ad` יחזיר **שדה נגזר אחד** — לא את הגלם, ו**לא את שם התאגיד**:

```
trust_level : 'verified' | 'registered' | 'unverified'
```

**המיפוי:**

| `trust_level` | תנאי |
|---|---|
| `verified` | `gov_registry_matched_at IS NOT NULL` **וגם** `approval_status = 'approved'` |
| `registered` | `approval_status = 'approved'`, בלי התאמה למרשם |
| `unverified` | כל השאר |

- **נגזר בשרת.** אל תשלח `verification_tier` גולמי לפרונט ותתן לו להחליט — **שני מקומות שמפרשים את אותו כלל יתפצלו**
- **דורש `JOIN` ל-`corporations`.** ⚠️ **שים לב לקוליישן** — `ads.owner_entity_id` הוא `0900_ai_ci` ו-`corporations.id` הוא `unicode_ci`. הדפוס כבר בקוד: `ads.py:790` עושה `c.id COLLATE utf8mb4_0900_ai_ci = a.owner_entity_id`. **בלי זה השאילתה תיפול על "Illegal mix of collations"**
- **אותו שינוי ב-`GET /ads/public/{ad_id}`** (`ads.py:541`)

## 2.2 · 🔴 שם התאגיד לא נכנס לתוצאות. נקודה.

> **Yulian, 10.09:** *"לא מציגים כחלק מתוצאות את השם — רק את התג, מאושר או לא."*

**שם התאגיד הוא חלק ממה ש-`contact-reveal` מוכר.** אם הוא יופיע חינם בתוצאות — **מכרנו את המוצר לפני התשלום.**

**Do — ואי-עשייה היא רוב העבודה כאן:**

- **אל תוסיף `corp_name` ל-`_serialize_ad` בכלל.** לא כשדה מותנה, לא `null`, לא "לשימוש עתידי"
- **אל תוסיף אותו ל-`GET /ads/public/{ad_id}`**
- השם ממשיך להגיע **רק** מ-`/ads/{id}/contact-reveal`, שכבר מחזיר `company_name` — **המנגנון קיים ונכון, אל תיגע בו**

**בתוצאות התג עומד לבדו.** `✓ תאגיד מאומת` הוא חיווי; `✓ כוח אדם גלובל` הוא הליד.

> **למה זה עדיף גם הנדסית:** שדה שמוחזר לפעמים דורש לוגיקה מותנית בשני מקומות, ומזמין דליפה בשינוי הבא. **שדה שלא קיים לא יכול לדלוף.**

# §3 · Frontend — התג בשורת התוצאה

**נכנס לפריסת H9**, בעמודת "מודעה" ליד הכותרת.

| | טקסט | טון |
|---|---|---|
| `verified` | `✓ תאגיד מאומת` | ירוק שקט |
| `registered` | `רשום במערכת` | אפור ניטרלי |
| `unverified` | `⚠ טרם אומת` | ענבר |

## הכללים

- 🔴 **אל תשתמש בענבר של `boosted`.** `border-amber-300` כבר אומר "מקודם". **שני מסרים שונים באותו צבע = אף אחד מהם לא נקרא.** בחר גוון אחר, או צורה אחרת (מסגרת מקווקוות, אייקון)
- **לא רק צבע** — כל תג נושא טקסט. WCAG, וגם עיוורי צבעים
- **ניגודיות ≥ 4.5:1**
- **`title`/`aria-label` מסביר:** `אומת מול מרשם קבלני כוח האדם של משרד הפנים` / `התאגיד רשום ולא אומת מול מרשם ממשלתי`
- **הנוסח לא מאשים.** `טרם אומת` — לא `לא מאומת` ובוודאי לא `לא אמין`. **תאגיד לגיטימי שטרם הועלה למרשם קיים, וזו לא אשמתו**

## §3b · שקיפות לתאגיד על עצמו

בדשבורד התאגיד, כשהוא **לא** `verified`:

```
המודעות שלך מוצגות לקבלנים עם התווית "טרם אומת".
[השלם אימות מול המרשם]
```

**זה הופך את התג ממכשול למנוע.** הכפתור מוביל ל-`GovRegistrySection` הקיים.
