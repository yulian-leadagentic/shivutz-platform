# §2 · מסך חיפוש אחד — וההחלטה שבתוכו

> **Yulian:** *"אני חושב שצריך להיות רק מסך חיפוש אחד שמחפש בכל המאגר."*

**מסכים, וזו המסקנה הנכונה.** שני מסכי חיפוש נפרדים על שתי טבלאות הם פער שהמשתמש לא אמור להכיר.

## 🔴 אל תאחד את הטבלאות

`ads` ו-`marketplace_listings` שונות בשדות, במחזור חיים, בבעלות ובמודל התשלום. **איחוד שלהן הוא פרויקט של שבועות, ואין אותם.**

## מה כן — חיפוש מאוחד, פדרטיבי

```
שאילתה אחת
   ├─ ads                    (הצינור הקיים — rewriter → SQL → rerank)
   └─ marketplace_listings   (חיפוש טקסט על title + description)
        ↓
תוצאות בשני מקטעים מסומנים:
   עובדים ודיור  ·  שירותים נלווים
```

- **הרץ את שתי השאילתות תמיד.** אל תנסה "לזהות כוונה" ולנתב — **ניחוש שגוי מחזיר בדיוק את הבאג של §1**
- **מקטע ריק לא מרונדר**
- **הסדר: מה שה-rewriter חילץ בביטחון קודם.** חילץ `profession_code` → עובדים ראשון. לא חילץ כלום אבל יש התאמת טקסט בשירותים → שירותים ראשון
- `marketplace_listings` — `LIKE` על `title` ו-`description` מספיק בנפח הזה. **אל תבנה full-text index עכשיו**

## §2b · `/marketplace` נשאר

**אל תמחק אותו.** הוא הופך ל**דף עיון לפי קטגוריה** — מגיעים אליו מהתפריט, לא מחיפוש.
**אבל החיפוש שבתוכו** (`?search=`) **חייב לתת אותן תוצאות** כמו המקטע בדף הבית. **אותה פונקציה, לא שתי מימושים.**

## §2b-1 · 🔴 באג הפיסוק — **אובחן. אל תחקור, תקן**

Yulian חידד: **`ביטוח` מחזיר תוצאות. `ביטוח,` — עם פסיק — לא מחזיר כלום.**

מצאתי את הסיבה. `services/user-org/app/routes/marketplace.py:139-142`

```python
if search:
    conditions.append("(ml.title LIKE %s OR ml.description LIKE %s OR ml.city LIKE %s)")
    like = f"%{search}%"
    params.extend([like, like, like])
```

**הקלט נכנס ל-`LIKE` כמו שהוא.** `%ביטוח,%` לא קיים באף שדה. **אין שום נרמול.**

> **זה לא מקרה קצה.** משתמש שמקליד `ביטוח, הסעות` או `דיור,` מקבל אפס תוצאות ומסיק שאין מלאי. **בעברית פסיק בסוף מילה הוא הקלדה נפוצה מאוד.**

### Do — נרמול בצד השרת, לפני ה-`LIKE`

```
1  strip
2  הסר פיסוק קצה:  , . ; : ! ? " ' ־ - ( )
3  כווץ רווחים כפולים
4  אם נשארו כמה מילים — פצל, ובנה AND של LIKE לכל מילה
5  מחרוזת ריקה אחרי הנרמול  →  התעלם מ-search, אל תחזיר אפס
```

🔴 **אל תסיר תווים מתוך מילה** — `ד"ר`, `בע"מ`, `צה"ל` חייבים לשרוד. **רק קצוות.**

⚠️ **`%` ו-`_` בקלט הם תווי wildcard של `LIKE`.** משתמש שמקליד `100%` מקבל היום התאמה לכל דבר. **escape אותם.**

🔴 **אותה פונקציית נרמול משרתת גם את §2.** פונקציה אחת, `normalize_search_term`, **לא שני מימושים** — זו בדיוק התבנית שיצרה את שבעת הבאגים.

### בדוק גם

- [ ] `ביטוח` · `ביטוח,` · `ביטוח, ` · ` ביטוח` → **כולם אותן תוצאות.** הדבק ארבע
- [ ] `בע"מ` → עדיין מוצא. **הגרשיים שרדו**
- [ ] `%` לבדו → **לא מחזיר את כל המאגר**
- [ ] `,` לבדו → כל המודעות, לא אפס
