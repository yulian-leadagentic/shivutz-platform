# CC prompt — H6: הסרגל הדביק מכסה את התוצאה הראשונה

## הבאג

צילום מסטייג'ינג, שאילתה `רצפים סינים`: **הכרטיס "רצפים סינים" חתוך מלמעלה — הסרגל הדביק יושב עליו.**

## Root cause — מאומת בקוד, לא השערה

```
page.tsx:771   <div className="sticky top-16 ...">     ← הסרגל
page.tsx:940   רצועת "הבנתי" מותקנת בתוך אותו slot     ← הצטרפה ב-F2
page.tsx:1290  className="... scroll-mt-16"            ← 64px, קבוע
page.tsx:1648  className="scroll-mt-36 ..."            ← 144px, קבוע
```

**F2 איחד את הרצועה לתוך הסרגל. מאותו רגע גובה הסרגל אינו קבוע:**

| מצב | גובה משוער |
|---|---|
| סרגל בלבד | ~72px דסקטופ · ~64px ב-390 |
| **סרגל + רצועת "הבנתי"** | **~120px+** |

**ו-`scroll-mt` הוא מספר קשיח.** כשהרצועה מופיעה, הסרגל גבוה מהריווח השמור → **הוא מכסה.**

> **זו לא רגרסיה של F2 — זו השלמה שחסרה בו.** הפרומט אמר לאחד את המשטחים ולא אמר לעדכן את הריווח. **הפער שלי.**

# 🔴 התיקון — חייב להיות דינמי

**אל תגדיל את `scroll-mt` למספר גדול יותר.** הגובה **משתנה בזמן ריצה**, וכל קבוע שתבחר יהיה שגוי באחד משני המצבים: קטן מדי כשיש רצועה, או משאיר חור לבן כשאין.

## Do

**1 · מדוד את הסרגל בפועל**

`ResizeObserver` על אלמנט הסרגל הדביק (`page.tsx:771`). בכל שינוי — כתוב את הגובה למשתנה CSS:

```js
document.documentElement.style.setProperty('--sticky-h', h + 'px');
```

**`ResizeObserver` ולא `useEffect` על state** — הגובה משתנה גם משבירת שורות, מרוחב מסך, ומכניסת תגים. **מדידה, לא ניחוש.**

**2 · השתמש בו בכל מקום שיש בו `scroll-mt` קשיח**

```css
scroll-margin-top: calc(var(--sticky-h, 72px) + 12px);
```

- `page.tsx:1290` — אזור התוצאות
- `page.tsx:1648` — כרטיס בודד
- **`grep -n "scroll-mt" app/page.tsx` — ותקן את כולם.** דווח כמה מצאת

**ה-fallback `72px` הכרחי** — לפני שה-observer רץ, אסור שהערך יהיה ריק.

**3 · הרווח מתחת לסרגל**

לא רק גלילה — גם במצב סטטי אסור שהכרטיס יישב מתחת לסרגל. **הוסף `padding-top` לאזור התוצאות מאותו משתנה**, או ודא שהסרגל אינו שקוף חלקית מעל התוכן.

> ⚠️ **הסרגל הוא `bg-white/95 backdrop-blur-sm`** — שקוף חלקית. **טקסט שמתחתיו נראה מטושטש ולא נעלם**, וזה גרוע יותר מכיסוי מלא כי זה נראה כמו באג רינדור. **חייב ריווח אמיתי, לא הסתמכות על הרקע.**

# §2 · WCAG 2.4.11 — לא לשבור מה שעבר

`2.4.11 Focus Not Obscured` עבר ב-SP2. **גובה משתנה מסכן אותו מחדש:** אם אלמנט ממוקד נגלל אל מתחת לסרגל שגדל — הוא מוסתר, וזה כשל.

**בדוק במפורש:** Tab דרך הכרטיסים אחרי חיפוש, **עם הרצועה מוצגת**, וּודא שאף אלמנט ממוקד לא נכנס מתחת לסרגל. **צילום.**
