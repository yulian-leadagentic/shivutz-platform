# §1 · המבנה — טבלה סמנטית, לא `<table>`

## 1.1 · הכלל

**`role="table"` על `<ul>` קיים, `role="row"` על `<li>`.** אל תחליף ל-`<table>` — הריווח, ה-sticky והשוליים בנויים סביב `ul/li`, והמעבר ל-390 (שחוזר לכרטיסים) יהיה עוין ב-`<table>`.

```
<ul role="table" aria-label="תוצאות החיפוש">
  <li role="row" aria-hidden="true">  ← שורת הכותרות
  <li role="row">                     ← AdCard
```

## 1.2 · הרשת — עובדים

```css
grid-template-columns: 1fr 92px 108px 96px 132px;
/*                   מודעה  כמות   מוצא   אזור  [כפתור] */
```

## 1.3 · הרשת — דיור

```css
grid-template-columns: 1fr 92px 108px 96px 132px;
/*                   מודעה  מיטות  עיר   ₪/מיטה [כפתור] */
```

> **אותה רשת, כותרות שונות.** אל תיצור שתי מערכות רוחב — ההיגיון הוויזואלי צריך להיות זהה בין שני סוגי המודעות.

## 1.4 · תערובת סוגים

`filters.ad_type` הוא ערך יחיד, ולכן בפועל סט תוצאות הוא הומוגני. **בכל זאת, הגן:** אם הסט מכיל את שני הסוגים — **קבץ לפי `ad_type` עם כותרת ביניים** (`עובדים` / `דיור`) ושורת כותרות משלה לכל קבוצה. **אל תרנדר עמודות מעורבות תחת כותרת אחת** — זה יציג מספר מיטות תחת הכותרת "כמות".

# §2 · העמודות

## 2.1 · שורת הכותרות

מעל השורה הראשונה, **פעם אחת לכל קבוצה**:

```
מודעה            כמות     מוצא      אזור
```

- `text-xs text-slate-500 font-semibold`
- `aria-hidden="true"` על השורה הוויזואלית, **ו-`aria-label` על כל תא בשורות עצמן** (`aria-label="כמות: 12"`). קורא מסך לא יקרא כותרת ויזואלית שנמצאת ב-`li` נפרד
- **לא sticky.** היא נגללת החוצה. סרגל דביק נוסף מעל הסרגל של H6 = שתי שכבות דביקות, וזה בדיוק הבאג שתיקנו

## 2.2 · עמודת המספרים — `tabular-nums`

```css
font-variant-numeric: tabular-nums;
```

**זה לא קישוט.** בלי זה `4` ו-`12` לא מתיישרים, והעין לא סורקת את העמודה אנכית — וכל הטעם בפריסה הזאת הוא הסריקה האנכית.

> **עמודת הכמות היא גם near-match גלוי.** קבלן שביקש 10 רואה מיד מי נותן 8 ומי 20, בלי לקרוא תג.

## 2.3 · `body_he` — יורד מהשורה

היום: `whitespace-pre-line` בגובה חופשי. **זה התורם הגדול ביותר לגובה, והוא טקסט שיווקי שאף אחד לא משווה לפיו.**

**Do:** `line-clamp-1` בתוך עמודת "מודעה", מתחת ל-`title_he`, ב-`text-xs text-slate-500`. **הטקסט המלא נפתח עם השורה** (§3).

## 2.4 · טרייוּת — אופציונלי, החלט ודווח

`published_at` זמין. `לפני 3 ימים` בעמודת "מודעה" הוא אות אמון חזק בקטלוג.

**אם זה נכנס בלי לדחוס את הכותרת — הוסף. אם זה דוחק, ותר ודווח.** אל תוסיף עמודה שישית בשבילו.

# §3 · הכפתור והמצב החשוף — הנקודה הקשה

**זה הסעיף שיכשיל את המימוש אם תמהר בו.**

## 3.1 · המצב הסגור

`הצג פרטי קשר` **נכנס לעמודה החמישית**, בגובה השורה. **בלי `border-t`, בלי שורה משלו.**

- אייקון + טקסט מקוצר בדסקטופ צר: `הצג פרטים`
- `min-height: 40px` — **אל תרד מ-44px שטח מגע ב-390** (שם ממילא חוזרים לכרטיס, §4)

## 3.2 · המצב החשוף — השורה **נפתחת**, לא מתרחבת לצדדים

הבלוק החשוף מכיל שם חברה, טלפון, מייל, הערת R2 והקישור הצולב של R4. **הוא לא נכנס לתא של 132px, ואסור לנסות.**

```
[ שורה רגילה                              ]
[ ← נפתחת שורה שנייה ברוחב מלא, מתחת ]
```

- `grid-column: 1 / -1` על הבלוק החשוף
- **הכפתור בעמודה החמישית מוחלף ב-`✓ נחשף`** — אינדיקציה שקטה, לא כפתור מת
- **כל התוכן של R2 ו-R4 נשמר במלואו.** הערת `נשמר לך — לא ייגבו חשיפות נוספות` והקישור הצולב **הם דרישות מוצר שהוכרעו** — הם עוברים לשורה הנפתחת, לא נמחקים
- אנימציית פתיחה מכובדת ל-`prefers-reduced-motion`

## 3.3 · דיור — תמונות ומתקנים

היום: גלריית `w-24 h-24` (96px) + צ'יפים. **ברשת של 40px גובה שורה זה בלתי אפשרי.**

- **סגור:** תמונה ראשונה בלבד, `w-10 h-10 rounded object-cover`, בתחילת עמודת "מודעה". **בלי תמונה — בלי מציין מקום.** אל תשמור רוחב לתמונה שאין
- **פתוח:** הגלריה המלאה (עד 4) והצ'יפים, בשורה הנפתחת

# §4 · 390 — חוזרים לכרטיס, עם תוויות

**רשת של חמש עמודות ב-390 היא באג, לא פריסה.**

מתחת ל-`sm` (640px): `grid-template-columns: 1fr`, וכל תא מקבל תווית שדה:

```html
<span data-l="כמות">12</span>
```
```css
[data-l]::before { content: attr(data-l) ": "; color: …; }
```

- **שורת הכותרות `display:none`** — התוויות החליפו אותה
- **הכפתור חוזר לרוחב מלא** בתחתית הכרטיס. ב-390 אין ריק לרוחב, ולכן הבעיה המקורית לא קיימת שם

> **זה שדרוג ל-390, לא רק שימור.** היום `· מוצא: סין · אזור: מרכז` הוא מחרוזת רצה; אחרי — שדות מתויגים. **המשתמש בטלפון מרוויח מהשינוי הזה בזכות עצמו.**
