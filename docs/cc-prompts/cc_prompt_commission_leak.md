# CC prompt — שריד "עמלה" באישור ארגון (פספוס ניקוי D3)

## הקשר
המוצר עבר pivot **מעמלה-לעסקה → מנוי/ליסטינגים**, והעמלות נמחקו ב-D3 (migration 067). אבל **דיאלוג האישור הקבוצתי ב-admin עדיין מציג copy של עמלה** — מאומת בצילום staging חי:

> "אישור קבוצתי — לאשר 4 ארגונים? **כל ארגון יקבל את העמלה שכבר הוגדרה לו בכרטיס.**"

מושג "עמלה" לא אמור להתקיים אחרי ה-pivot. זה מבלבל את בעל המוצר ומטעה אדמינים.

`git tag pre-commission-leak` לפני. staging בלבד. דווח: אם זה רק copy או גם שדה/דאטה חי.

## Do
1. **אתר את המקור:** grep ב-`services/frontend/src/app/admin` (מסך אישורים/approvals + כרטיס ארגון) על `עמלה|commission|per_worker|amount`. אתר את הדיאלוג "אישור קבוצתי".
2. **הכרע — copy בלבד או שדה חי:**

3. **ודא שאין עוד אזכורי עמלה** בזרימת ה-admin (כרטיס ארגון, אישור בודד, טולטיפים).
