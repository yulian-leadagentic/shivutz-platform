# §1 · הסכימה — טבלה אחת

מיגרציה חדשה. **בדוק את המספר הפנוי** (`ls db/migrations | tail`) — אל תסתמך על מספר שכתוב פה.

```sql
CREATE TABLE sponsor_ads (
  id              CHAR(36)     NOT NULL PRIMARY KEY,
  advertiser_name VARCHAR(120) NOT NULL,

  -- קריאייטיב
  headline_he     VARCHAR(120) NOT NULL,
  body_he         VARCHAR(200)     NULL,
  chips_he        JSON             NULL,   -- ["חיתוך קרמיקה","פלס לייזר"]
  cta_label_he    VARCHAR(40)  NOT NULL,
  cta_url         VARCHAR(500)     NULL,   -- NULL = לא לחיץ (מצב הדגמה)
  logo_url        VARCHAR(500)     NULL,
  brand_bg        CHAR(7)          NULL,   -- #000000
  brand_fg        CHAR(7)          NULL,   -- #e0a605

  -- מיקוד
  target_professions JSON          NULL,   -- ["flooring"] · NULL = הכל
  target_ad_types    JSON          NULL,   -- ["worker"]   · NULL = הכל
  target_regions     JSON          NULL,   -- NULL = הכל

  -- מחזור חיים
  active     BOOLEAN   NOT NULL DEFAULT FALSE,
  starts_at  DATETIME      NULL,
  ends_at    DATETIME      NULL,
  sort_order INT       NOT NULL DEFAULT 0,
  is_seed    BOOLEAN   NOT NULL DEFAULT FALSE,
  created_at DATETIME  NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME  NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

  INDEX idx_sponsor_active (active, starts_at, ends_at)
);
```

- **`NULL` במיקוד = ללא מיקוד**, לא "אף אחד". איילון היא `target_ad_types=["worker","housing"]`, `target_professions=NULL`
- **`active` ברירת מחדל `FALSE`.** מודעה חדשה לא עולה לאוויר בטעות
- **`is_seed`** — אותו כלל מ-H7. כל שורה שהסידר יוצר מסומנת

# §2 · Backend — endpoint אחד

```
GET /ads/public/sponsored?profession=<code>&ad_type=<type>&region=<code>&limit=2
```

**ציבורי, ללא אימות** — כמו `/public/recent`.

## הבחירה

```
1. active = TRUE
2. (starts_at IS NULL OR starts_at <= NOW())
   AND (ends_at IS NULL OR ends_at >= NOW())
3. סינון רך על שלושת שדות המיקוד:
      target_professions IS NULL  OR  <code> ∈ target_professions
   ← NULL תמיד עובר. זה אותו דפוס `(col IS NULL OR col = %s)` שכבר בשימוש בחיפוש
4. מיון:  מדויק לפני כללי  →  sort_order  →  RAND()
5. LIMIT
```

> **למה `RAND()` בסוף:** בלי זה אותו מפרסם יופיע תמיד ראשון, ומפרסם שני לא ייראה לעולם. **`RAND()` על טבלה של עשרות שורות זול. אם היא תגדל לאלפים — נחליף.**

> ⚠️ **אותה מלכודת סדר-נתיבים מ-H11:** `@router.get("/{ad_id}")` בשורה 446 **יבלע** נתיב שמוגדר אחריו. **הגדר ליד שאר ה-`/public/*`, ואמת שלא חוזר 403.**

# §3 · Frontend — ההזרקה

## 3.1 · הכללים — הם ההחלטה, לא הפריסה

| כלל | ערך | למה |
|---|---|---|

| תקרה | **2 לכל סט** | |
| רצפה | **פחות מ-4 תוצאות ⇒ 0 מודעות** | אין מספיק תוכן שהמודעה תשב בתוכו |
| ריק | **אין מפרסם ⇒ הסלוט לא קיים ב-DOM** | **הכלל מ-F3.** בלי "מקום פרסום זמין", בלי מקום שמור |
| ספירה | **לא נספרת ב-`total`** | ולא זזה כשמסננים |
| תווית | **`מודעה`, קבועה, לא ניתנת לרכישה** | |

## 3.2 · הפריסה

- **`grid-column: 1 / -1`** — יוצאת מרשת חמש העמודות של H9, ברוחב מלא
- **גובה ≤ 88px בדסקטופ.** מודעה גבוהה משלוש שורות תוצאה שוברת את הסריקה האנכית
- מבנה: `[לוגו 92px] [כותרת + הסבר + צ׳יפים] [CTA]`
- **390:** הלוגו והטקסט זה לצד זה, ה-CTA ברוחב מלא מתחת
- `cta_url IS NULL` ⇒ **ה-CTA הוא `<span>`, לא `<a>`.** לא קישור מת, לא `href="#"`

## 3.3 · 🔴 המסגרת ניטרלית — הצבע רק בפנים

**זו ההחלטה החשובה ביותר בסעיף הזה.**

בראנד שחור-זהב ואיילון בורדו-לבן הם שני עולמות ויזואליים מנוגדים, ושניהם זרים לנייבי-אמרלד של הפורטל.

```
✅ מסגרת הסלוט:  אפור ניטרלי קבוע + תווית "מודעה"     ← המערכת שולטת
✅ בתוך המסגרת:  brand_bg / brand_fg של המפרסם        ← המפרסם שולט
❌ אסור:         brand_bg על רקע הסלוט או על גבולו
```

**בלי זה, כל מפרסם חדש שובר את המסך מחדש.**

## 3.4 · הבחנה מ"מקודם" של תאגיד

**שני סוגי "ממומן" באותו מסך.** אם ייראו דומה — ה-boost שתאגיד משלם עליו ייקרא כפרסומת חיצונית **ויאבד ערך.**

| | תאגיד מקודם | מפרסם חיצוני |
|---|---|---|
| מבנה | **שורה רגילה** ברשת העמודות | **בלוק** מחוץ לרשת, רוחב מלא |
| רקע | ענבר בהיר | אפור ניטרלי |
| תווית | `מקודם` | `מודעה` |

**ההבחנה כבר מבנית ולא רק צבעונית — זה נכון. אל תשטח אותה.**

## 3.5 · נגישות

- **`aria-label="מודעה מאת <advertiser_name>"`** על הסלוט
- **הסלוט אינו `<li>` של רשימת התוצאות הסמנטית.** רשימה עם `role="table"` שיש בה שורה שאינה תוצאה — **מבלבלת קורא מסך.** מחוץ ל-`role`, או `role="presentation"`
- ניגודיות: **`brand_fg` על `brand_bg` חייב 4.5:1.** בדוק את שני הזוגות שנזרעים ודווח מספרים
