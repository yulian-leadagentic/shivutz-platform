# §1 · SEC-1 — חמישה נתיבים בלי שום בדיקת בעלות

## מה מצאתי

חמישה נתיבים מקבלים `org_id` ב-URL, **ומחזירים את הרשומה בלי לבדוק שהקורא שייך לארגון**. כל משתמש מחובר — קבלן, תאגיד, כל אחד — שמנחש או משיג UUID, מקבל:

| נתיב | מה דולף |
|---|---|
| `contractors.py:655` — `GET /organizations/contractors/{org_id}` | פרופיל קבלן מלא |
| `contractors.py:693` — `.../contractors/{org_id}/users` | **רשימת משתמשים כולל טלפונים** |
| `corporations.py:518` — `GET /organizations/corporations/{org_id}` | פרופיל תאגיד מלא |
| `corporations.py:558` — `.../corporations/{org_id}/users` | **רשימת משתמשים כולל טלפונים** |
| `corporations.py:833` — `.../corporations/{org_id}/documents` | **כתובות הקבצים שהועלו** |

**התקדים לתיקון כבר קיים בקוד:** `_require_corp()` ב-`ads.py:65-70`, ובדיקות `caller_role` inline ב-`corporations.py:704-829`.

## Do

**עוזר אחד, משותף.** אל תשכפל את הבדיקה חמש פעמים.

```
require_entity_access(x_entity_id, x_entity_type, org_id, entity_kind)
  → 401 אם חסרים headers
  → 403 {"error":"not_your_entity"} אם x_entity_id != org_id
  → אדמין עובר תמיד
```

- **מקור הזהות הוא ה-headers מהגייטוויי בלבד.** `gateway/src/index.js:259-263` מזריק אותם מה-JWT ומוחק כשאין טוקן — **לא ניתן לזייף**
- **אדמין:** `x-user-role == 'admin'`. הגייטוויי כבר חוסם `/api/admin` בשורה 274, אבל הנתיבים כאן **אינם** תחת `/api/admin` — לכן הבדיקה חייבת להיות כאן
- **`corporations.py:833` (מסמכים) — הכי רגיש.** אחרי התיקון ודא שגם ה-URL-ים עצמם מוגנים; ראה §2

## §1b · סרוק את השאר

```bash
grep -rn "^@router\.\(get\|patch\|delete\|post\)" services/user-org/app/routes/*.py
```

**לכל נתיב שמקבל `org_id`/`entity_id` ב-path — דווח אם יש לו בדיקה.** תקן את מה שנוגע בנתוני ארגון. **דווח את השאר, אל תיגע.**

> ⚠️ **`services/admin` אין בו קוד הרשאה בכלל** — הוא נשען לגמרי על חסימת `ADMIN_ONLY` בגייטוויי, ו-`x-user-id` מקבל שם ברירת מחדל `"admin"` (`approvals.py:254,280,315`). **אל תתקן את זה עכשיו** — דווח כפריט נפרד.

# §2 · SEC-2 — אחסון הקבצים פתוח לגמרי

## מה מצאתי

`gateway/src/index.js:162-168` — **`/api/uploads` יושב ב-`PUBLIC_PREFIXES`**. כל קובץ שהועלה מוגש למי שיודע את שם הקובץ, **בלי טוקן**. יש בקוד הערה שמודה בפער.

**מה שם:** רישיונות תאגיד, תעודות, מסמכי זיהוי שקבלנים ותאגידים העלו באונבורדינג.

> **"השם הוא UUID אז זה בסדר" — לא.** כתובת קובץ דולפת דרך היסטוריית דפדפן, לוגים, Referer, שיתוף קישור וצילום מסך. **אבטחה דרך אי-ידיעת-הכתובת היא לא אבטחה.**

## Do

**זו הכרעה ארכיטקטונית קטנה. בחר, ודווח מה בחרת ולמה.**

**א׳ · פרוקסי מאומת** — `/api/uploads` יוצא מ-`PUBLIC_PREFIXES`; השירות מאמת שהקורא שייך לארגון שהקובץ שייך לו, ואז מזרים אותו.
**ב׳ · כתובות חתומות בתפוגה** — הקובץ נשאר מאחורי אחסון, והשרת מנפיק URL חתום לזמן קצוב.

**ההמלצה: א׳** — הוא קטן יותר, לא דורש תשתית חדשה, ומספיק לנפח הנוכחי. **ב׳ נכון בקנה מידה, ואין לו קונטקסט בשבועיים.**

- **צריך לדעת מי הבעלים של כל קובץ.** אם אין טבלת קבצים עם `owner_entity_id` — **דווח את זה לפני שאתה בונה**, זה משנה את ההיקף
- ⚠️ **בדוק מה נשבר.** לוגו, אווטאר או תמונת מודעה שמוגשים מאותו נתיב **יפסיקו להיטען** ברגע שהוא נסגר. **מפה את כל סוגי הקבצים לפני**, והפרד: נכסים ציבוריים בנתיב ציבורי, מסמכים מאחורי אימות
