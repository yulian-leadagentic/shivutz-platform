# §5 · `/marketplace` — שטחי מפרסמים

## מה שקיים ומה שחסר

**קיים:** טבלת `sponsor_ads` (069) עם קריאייטיב, מיתוג, טרגוט, `active`/`starts_at`/`ends_at`, ורכיב התצוגה מ-H10.

**חסר:** **אין ב-`sponsor_ads` שום מושג של *איפה*.** כל השורות היום הן שיבוץ בין תוצאות חיפוש.

## 5a · מיגרציה `078` — ממד השיבוץ

```sql
USE org_db;
ALTER TABLE sponsor_ads ADD COLUMN placements JSON NULL AFTER target_regions;
UPDATE sponsor_ads SET placements = JSON_ARRAY('search_inline') WHERE placements IS NULL;
```

**שלושה ערכים:** `search_inline` · `marketplace_banner` · `marketplace_carousel`.

🔴 **קריטי — `NULL` כאן אינו "הכל".** בשאר עמודות הטרגוט ב-069, `NULL` פירושו "בלי טרגוט בציר הזה", כלומר כולם. **כאן זה היה גורם לשלוש מודעות הזרע הקיימות להופיע פתאום כבאנר בשוק.** לכן ה-`UPDATE`, **ובקריאה: `NULL` ≡ `search_inline` בלבד.** תעד את זה בהערה מעל העמודה — **ההפרש מהמוסכמה של 069 חייב להיות כתוב, אחרת מישהו "יתקן" אותו.**
