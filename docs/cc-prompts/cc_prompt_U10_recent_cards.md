# §1 · אבחון — הוא צודק, והבדיקה בקוד חד־משמעית

`services/frontend/src/app/page.tsx:1880-1917` — מקטע `פרסום חדש בפורטל`.

```tsx
{recent.slice(0, 9).map((ad) => {
  return (
    <div key={ad.id} className="rounded-2xl border border-slate-200 bg-white p-4 shadow-sm">

```

**`<div>`. אין `<Link>`, אין `href`, אין `onClick`. הכרטיס אינו יעד ניווט — הוא קישוט.**

> **קרוסלת "חם בפורטל" מקשרת נכון. המוזאיקה שמתחתיה לא.**
> **שני מקטעים באותו דף, מציגים את אותו סוג פריט, אחד לחיץ והשני לא. המשתמש לא יכול להסיק כלל מזה — הוא פשוט חושב שהאתר שבור.**

# §2 · Do — אותה תבנית, לא תבנית חדשה

- **עטוף את הכרטיס ב-`<Link href={`/?ad=${ad.id}`}>`** — **בדיוק כמו הקרוסלה.** 🔴 **אל תמציא מסלול חדש** (`/ads/{id}`) בלי לבדוק שהוא קיים ועובד; פרמטר `?ad=` הוא מה שמנגנון החשיפה של H11 כבר יודע לקרוא
- **`<Link>` של Next, לא `<a>`** — ניווט צד־לקוח. ⚠️ **אם `<a>` נבחר בקרוסלה בכוונה (רענון מלא כדי לאפס state), דווח ועשה כמוה.** אל תשנה את שתיהן לצורות שונות
- **מצבי hover ו-focus** — הכרטיס נראה היום סטטי. `hover:shadow-md` + `focus-visible:ring`
- 🔴 **נגישות:** הכרטיס צריך להיות יעד `Tab` אחד עם שם נגיש ברור. **`aria-label` עם הכותרת** — לא תשעה כרטיסים שכולם נקראים "קישור"
- **אזור הלחיצה — כל הכרטיס**, לא הכותרת בלבד. במובייל זה ההבדל בין עובד ללא עובד

## §2b · ⚠️ מה קורה כשאנונימי לוחץ

**זו השאלה האמיתית מאחורי התיקון.**

- **המודעה עצמה ציבורית לצפייה** — ההרשמה נדרשת רק לחשיפת פרטי קשר
- **שרשרת החזרה מ-H11 / U5 §1 חייבת לעבוד:** לחיצה → אם נדרשת התחברות → אחריה **חזרה לאותה מודעה**, לא לדף חיפוש ריק
- 🔴 **בדוק את זה בחלון פרטי, מקצה לקצה.** **זה הבאג המקורי שפתחת איתו את כל הסבב (H11), ומקטע שלא היה לחיץ מעולם לא נבדק מולו**
- `services/frontend/src/features/prospect/returnTo.ts` — **המנגנון קיים. ודא שהמסלול הזה נכנס אליו ולא עוקף אותו**

# §3 · ⚠️ הקודים הגולמיים בצילום — **ייתכן שכבר תוקנו. בדוק לפני שתתקן שוב**

בצילום של Yulian מופיע כרטיס `רצפים סינים` ותחתיו **`flooring · CN · 20 עובדים`**.

**אבל בקוד שקראתי, שורות 1901-1908, כבר יש:**

```tsx
{/* U8 §1 — was rendering raw enum codes (`flooring`, `CN`) … */}
{ad.profession_code && <span>{labelFor(professions, ad.profession_code)}</span>}
{ad.origin_country  && <span>· {labelFor(origins,     ad.origin_country)}</span>}
```

**כלומר U8 §1 כבר נגע במקטע הזה.**

🔴 **אל תתקן את זה שוב.** **דווח אחד משלושה:**

| | |
|---|---|
| **סטייג'ינג לא נפרס מאז U8** | הצילום ישן. **אמור זאת ל-Yulian במפורש** |
| **נפרס, ועדיין מציג קודים** | **`labelFor` מחזיר את הקוד** — כנראה `professions`/`origins` ריקים במסך הזה. **זה באג אחר: ה-enums לא נטענו.** חקור |
| **נפרס ותקין** | סגור. ציין ועבור הלאה |

⚠️ **ההערה בקוד מציינת ש-`labelFor` כאן הוא העוזר המקומי מבוסס־המערך, ולא זה מבוסס־המפה שב-`lib/labels.ts`.** **אם U8 יצר `lib/labels.ts`, שני עוזרים לאותה מטרה זה בדיוק מה ש-U8 §1 בא לסגור. דווח.**
