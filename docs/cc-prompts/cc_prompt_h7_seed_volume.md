# שלב 1 · מה יש עכשיו

```sql
SELECT ad_type, profession_code, origin_country, region, COUNT(*)
FROM ads WHERE active = TRUE AND deleted_at IS NULL
GROUP BY 1,2,3,4 ORDER BY 1,2;

SELECT COUNT(*) FROM corporations;
SELECT COUNT(*) FROM contractors;
SELECT code, name_he FROM profession_types WHERE is_active = TRUE;
```

**דווח לפני שאתה זורע.**

> ⚠️ **הבאג המוכר בסידר:** בסבב קודם נוצרו **שני תאגידים בלבד** בגלל התנגשות `business_number`, ומודעות הדיור קיבלו 2 שורות. **`uq_business_number` הוא UNIQUE.** ודא שהסידר מייצר ח.פ ייחודי לכל תאגיד ו**נכשל בקול** אם לא — לא בולע.

# שלב 2 · 🔴 דגל הזרע — לפני כל שורה שנכתבת

```sql
ALTER TABLE ads          ADD COLUMN is_seed BOOLEAN NOT NULL DEFAULT FALSE;
ALTER TABLE corporations ADD COLUMN is_seed BOOLEAN NOT NULL DEFAULT FALSE;
ALTER TABLE contractors  ADD COLUMN is_seed BOOLEAN NOT NULL DEFAULT FALSE;
```

**כל שורה שהסידר יוצר — `is_seed = TRUE`.**

> **למה זה חובה ולא נחמד-שיהיה:** ביום שיהיה תאגיד אמיתי אחד, נצטרך להבדיל. **בלי הדגל, "למחוק את דאטת הבדיקה" יהפוך לעבודה ידנית מסוכנת** — וזו בדיוק הדרך שבה דאטת מוק נשארת בפרודקשן.
>
> **בשלב הזה הדגל לא מסנן כלום** — הוא רק מסומן. הסינון יגיע כשיהיה מה לסנן.

# שלב 3 · הזריעה

## תאגידים — 6+

**שמות שונים, ח.פ ייחודי, אזורי פעילות שונים.** חלקם עם `gov_registry_matched_at` מלא וחלקם בלי — **כדי שנוכל לבדוק את תג "מאומת" בשני המצבים.** ⚠️ **אל תמציא ח.פ שנראה אמיתי** — השתמש בטווח שמור לבדיקות ותעד אותו.

## קבלנים — 4+

**זה גם פותר חסם ותיק:** ה-harness נכנס רק כישות קבלן, ולכן מסכי `corporation__*` ו-`admin__*` יצאו `NoAccessCard`. **עם כמה קבלנים ותאגידים אפשר סוף-סוף לבדוק דו-ישותי.**

## מודעות עובדים — 5+ לכל מקצוע

**לכל מקצוע, פזר על פני:**

- **מוצא:** סין · אוקראינה · מולדובה · הודו · תאילנד · פיליפינים · אוזבקיסטן · רומניה · סרי לנקה
- **אזור:** צפון · מרכז · דרום · כל הארץ
- **כמות:** 2 · 4 · 8 · 12 · 20 — **טווח אמיתי**, כדי שמסנן הכמות יהיה משמעותי
- **תאגיד מפרסם:** מפוזר על כל השישה, לא כולם על אחד

> 🔴 **שתי שאילתות חייבות להחזיר 3–8 תוצאות אחרי הזריעה** — הן צ'יפים במסך הראשון:
> `רצפים סינים` · `אני צריך טייחים במרכז`
> **אל תכוון אליהן במיוחד** — פזר נכון והן ייפלו לטווח מעצמן. **אם לא — דווח, אל תזייף.**

## מודעות דיור — 10+

**עם השדות שקיימים ב-`056` ואיתם:**

- `total_beds` · `available_beds` — **חלק מלאות, חלק חלקיות.** `10/10`, `5/10`, `2/8`, `12/12`
- `origin_country` — **על החלקיות בלבד.** דירה מלאה = אין מוצא, אין עובדה לתאר
- `rental_mode` — `whole_unit` · `beds` · `both`, ו**חלק `NULL`** כדי לוודא שהסינון הרך עובד
- `city` — ת״א · פ״ת · חיפה · אשדוד · ירושלים · באר שבע
- `price_per_bed_nis` — טווח אמיתי

## הטקסט

**עברית אמיתית, לא lorem ולא מחרוזות זהות.** `סינים מעולים עם הרבה ניסיון` הוא הטון הנכון. **תיאור שונה לכל מודעה** — הקטלוג צריך להיראות כמו קטלוג, לא כמו לולאה.
