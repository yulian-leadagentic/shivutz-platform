# 🎯 המשימות — לפי בעלים

## 🟠 Yulian

**Y-1 · לפתור את תעלומת ה-401 — 2 דקות** 🔴
`dbbcbd8` הוסיף לוג ב-`services/gateway/src/auth.js` שמסווג את סיבת הכישלון. אחרי הפריסה:
```
docker logs gateway | grep -i "auth\|token"
```
התוצאה מכריעה מיידית:
- `no_token` → הבדיקה של CC הייתה פגומה (חסר `Bearer `). **אין באג בסטייג'ינג**
- `no_secret` → `JWT_SECRET` לא הגיע לתהליך → **רידיפלוי ל-gateway**
- `bad_signature` → הסודות באמת שונים (כנראה רווח נסתר) → יישר ורידיפלוי
- `expired` → בעיית TTL/שעון

**בדיקה חלופית של 60 שניות:** תיכנס בדפדפן ל-`/billing`. נטען = אין בעיה. אדום = יש.

**Y-2 · לאמת שה-LLM באמת רץ — 1 דקה**
```
docker logs user-org | grep '\[qrewrite\]'
```
צריך `mode=real`. אם `mode=fake reason=no_api_key` — המפתח לא הגיע ל-`user-org`.

**Y-3 · WhatsApp שלבים A+B — 20 דקות** 🟢 **לא ממתין לכלום**
