# §1 · סימן ה-AI — אלמנט אחד, שלושה תפקידים

```
בכותרת:   פלטפורמת ה[AI] לקבלנים ותאגידי כוח אדם
במנוחה:   [ מה אתה מחפש?                    [AI] ]
בהקלדה:   [ רצפים סינ[AI]                        ]
```

**זה לא שלושה עיטורים.** המשתמש פוגש את אותו סימן בשלוש נקודות, וכל פגישה מחזקת את הקודמת.

## 🔴 שלוש דרישות — פספוס של אחת שובר את הכול

### א׳ · `dir="ltr"`
```html
<span class="ai-mark" dir="ltr" aria-hidden="true">AI</span>
```
+ `unicode-bidi:isolate` ב-CSS.
**בלי זה האותיות מתהפכות ל-`IA` בתוך משפט עברי.**

### ב׳ · הסימן שבתיבה **נוצר פעם אחת ולא נבנה מחדש**
נשאר ב-DOM לכל אורך חיי העמוד. משתנה **class בלבד**.
**נבנה מחדש בכל מחזור ⇒ שני אלמנטים שמתחלפים ⇒ האפקט אובד.**
*(הסימן שבכותרת הוא מופע נפרד וסטטי — זה בסדר.)*

### ג׳ · הנסיעה **לא מתוכנתת**
הסימן יושב **בזרימת הטקסט**; התווים מוזרקים **לפניו**.
**בלי `position:absolute` על הסימן, בלי חישובי מיקום, בלי FLIP.** ה-RTL עושה את הנסיעה.

/* מנוחה — גדול ומלא */

**`brand-50` הוא ה-wash הבהיר. אם אין טוקן — דווח ואל תמציא.**
**מצב כהה: מדוד מול המשטח הכהה, בחר גוון בהיר מאותה משפחה, ודווח את שני היחסים.**

# §2 · הארכיטקטורה

```
.field (position:relative)
  ├─ <input>       הקלט האמיתי, controlled React. padding-inline-start
  │                שמור למקום הסימן במנוחה
  └─ .demo-ghost   position:absolute; inset:0; pointer-events:none;
                   aria-hidden="true"
       └─ [טקסט הדמו][.ai-mark]
```

> 🔑 **שכבת הדמו והקלט של המשתמש מוציאות זו את זו.** ברגע שהמשתמש נוגע — הדמו מת לצמיתות (§4). **אין IME לסנכרן, אין paste, אין binding דו-כיווני.**

- דמו כבוי → טקסט ריק → הסימן לבדו בקצה המוביל = "נח בתיבה"
- דמו פועל → `insertAdjacentText("beforebegin", ch)` → הטקסט דוחף אותו
- המשתמש מקליד → ה-ghost ריק, הסימן חונה בקצה. **תקין ורצוי**

ה-`<input>` נשאר controlled רגיל. `VoiceInputButton`, IME, paste, form semantics — **ללא שינוי**.

# §3 · הדמו החי

```
1 · מנוחה                                    0.5 שנ׳
2 · השאילתה מוקלדת (44ms/תו + רעש)           ~1.0 שנ׳
3 · קו סריקה על אזור התוצאות                 1.9 שנ׳   ← איטי בכוונה
4 · התיבה ורצועת "הבנתי" מתאחדות (§5)
5 · התגים נופלים מלמעלה, stagger 105ms
6 · הכרטיסים נכנסים, stagger 120ms
7 · "סינון מתקדם" מופיע                      +700ms
8 · החזקה                                    3.6 שנ׳
9 · דהייה, מחיקה (18ms/תו), חזרה למנוחה
```

**קו הסריקה — 1.9 שניות, `cubic-bezier(.35,0,.3,1)`, גובה 3px.** צריך להיראות **סורק**, לא מהבהב.

**התגים נכנסים מלמעלה** — `translateY(-14px)` → 0. הם צריכים להיראות **נופלים מהתיבה**, כי משם הם באו.

# §4 · העצירה

```
pointerdown · keydown · focusin · wheel  →  עצירה לצמיתות
```

**במצב עצירה השדה עובר למשתמש:** הטקסט של הדמו **נמחק** · הסימן ל-`is-rest` בלי הבהוב · ה-placeholder האמיתי מופיע · המסגרת כבה · האיחוד מתפרק.

> **אסור להשאיר את המשתמש מול טקסט שהוא לא כתב.** לחיצה על "חפש" שתחפש את שאילתת הדמו — באג חמור.

## נגישות
- **WCAG 2.2.2** — העצירה היא המנגנון. תעד בהערה בקוד
- **`prefers-reduced-motion: reduce` → הלולאה לא רצה בכלל.** לא "מהר יותר"
- **`aria-hidden="true"`** על הסימן ועל כל שכבת הדמו
- **`aria-live` לא מכריז על הלולאה.** רק על חיפוש שהמשתמש יזם. **הכרזה = רגרסיה חמורה**

# §5 · 🔴 מבנה החצי העליון — שינויים מבניים

## 5.1 · הכותרת עולה לבלוק הראש

**בלוק ה-hero מבוטל.** הכותרת הופכת לחלק מבלוק הראש, יחד עם הלוגו והתפריט.

```
הנוסח:  פלטפורמת ה[AI] לקבלנים ותאגידי כוח אדם
```

- **דסקטופ:** אם נכנס — שורה אחת עם הלוגו והתפריט
- **390:** 44px לא מכילים לוגו + תפריט + CTA + משפט. **הכותרת בשורה משלה, מתחתיהם, בתוך אותו בלוק ראש** — אותו רקע, אותו גבול תחתון. **לא בלוק נפרד**
- **🔴 תגית `<h1>` נשמרת.** עוטפים **רק את שתי האותיות** ב-`<span class="ai-mark ai-mark--hl">`. **המשפט חייב להישאר רציף לקוראי מסך ול-SEO** — אל תפצל אותו ל-spans

**כותרת המשנה `לעובדים זרים בענף הבנייה` — נמחקת.** הכותרת החדשה כבר אומרת למי זה.

## 5.2 · התיבה ורצועת "הבנתי" — **משטח אחד**

זהו הקשר בין השאילתה לתוצאות. **אין חץ ואין קו מקשר — האיחוד עצמו הוא הקשר.**

```css
/* כשיש תוצאות */
.search-bar.is-joined{
  border-radius:14px 14px 0 0;
  border-bottom-width:0;
  box-shadow:none;
}
.readout{
  border:2px solid var(--brand-600); border-top:0;
  border-radius:0 0 14px 14px;
  background:var(--brand-50);
}
```

קלט למעלה, פרשנות מיד מתחתיו, **בלי רווח ובלי קו מפריד**. הכרטיסים תלויים מזה.
**בלי תוצאות — התיבה חוזרת לפינות מלאות.**

## 5.3 · הצ'יפים — **יורדים לגמרי**

ארבעת הכרטיסים שהומרו לצ'יפים ב-F1 **נמחקים מהמסך.**
**הלולאה עושה את עבודתם וטוב יותר** — צ'יפ *מציע* שאילתה, הלולאה *מריצה* אותה ומראה מה חזר.

> **הערה ל-F1:** זה מבטל את §1 ו-§1b של F1. **אל תמחק את הקוד** — הפוך אותו לרכיב שלא מרונדר, כדי שיהיה זול להחזיר אותו **מתחת** לתוצאות אם יתברר שמשתמשים תוקעים.

## 5.4 · "סינון מתקדם" — מוסתר עד שיש תוצאות

`opacity:0; pointer-events:none` → נחשף רק כשיש תוצאות. **אין מה לסנן לפני שיש מה.**
נשאר קישור טקסט משני. **לא כפתור.**
