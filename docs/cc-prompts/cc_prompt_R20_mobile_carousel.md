## ⚠️ ושתי נקודות שהופכות את זה למחסום מסחרי, לא לעיצוב

**א. הגילוי הנאות ב-bizi הוא דרישה חוקית.**

> *״לעסקים עם מחזור הכנסות של 400,000 ש״ח לפחות… ישראכרט אינה צד ואינה אחראית…״*

**פרסום פיננסי בישראל מחויב בגילוי הזה.** **רינדור שחותך או מקטין את התמונה הופך אותו לבלתי קריא — ואז המפרסם לא יכול להריץ אצלנו את המודעה מבחינה רגולטורית.**

🔴 **וזו בדיוק הקטגוריה שהכי מסוגלת לשלם.** ״ביטוח״ כבר קטגוריה פעילה אצלנו. **בנקים, אשראי וביטוח הם גם המפרסמים העשירים וגם אלה עם דרישות הקריאייטיב הנוקשות ביותר.**

**ב. שתי הדוגמאות ביחסי גובה-רוחב שונים** — 1:1 ו-~4:5. **כל פתרון שמניח יחס קבוע יחתוך אחת מהן.**

## מה שאני מציע — ⚠️ **אל תבנה. תכנן ודווח.**

```sql
creative_url     VARCHAR(500) NULL   -- התמונה המוגמרת
creative_w       INT          NULL   -- למניעת CLS
creative_h       INT          NULL
```

```
creative_url מלא   →  מרנדרים את התמונה. headline/body/chips מתעלמים
creative_url ריק   →  המודל הקיים, ללא שינוי
```

- **`object-fit: contain`. לעולם לא `cover`.** חיתוך = גילוי נאות אבוד
- **`alt` חובה** — נגישות, ו-`advertiser_name` אינו תחליף לתיאור המודעה
- **Cloudinary כבר מחובר** — אותו מסלול העלאה של תמונות המודעות
- **`aspect-ratio` מ-`creative_w/h`** כדי שהעמוד לא יקפוץ בטעינה

🔴 **בסבב הזה: אל תכתוב מיגרציה ואל תיגע בסכימה.**
**כתוב דוח קצר: מה נדרש, כמה קבצים, ומה הסיכון. Yulian מחליט אם זה נכנס לפני 14.10 או אחריו.**
