# §2 · כסף — השכבה שאין עליה שום בדיקה היום

## 🔴 2.1 · אידמפוטנטיות ה-webhook

```
1  ספור payment_events                                  → before
2  שלח webhook חתום עם provider_transaction_id = X      → 200
3  שלח את אותו payload בדיוק שוב                        → 200
4  ספור                                                 → after
5  ASSERT after - before == 1
6  ASSERT COUNT(WHERE provider_transaction_id = X) == 1
7  ASSERT current_period_end הוארך פעם אחת בלבד
```

**שורה 7 היא הבדיקה האמיתית.** שורה אחת ב-DB לא מוכיחה שההארכה לא קרתה פעמיים.

## 🔴 2.2 · אידמפוטנטיות אצוות החידוש

```
1  צור מנוי זרע שפג  (current_period_end בעבר, is_seed)
2  הרץ renewal-batch  →  קרא current_period_end
3  הרץ renewal-batch שוב, מיד
4  ASSERT current_period_end לא זז פעם שנייה
5  ASSERT נוצרה שורת payment_events אחת
```

> **חיוב כפול הוא באג ההשקה הגרוע ביותר שקיים.** הוא לא מתגלה במעבר ידני, הוא מתגלה בתלונה של לקוח.

## 2.3 · אבטחת ה-webhook

- בלי חתימה → **401**, **ואפס שורות `payment_events` חדשות**
- חתימה שגויה → **401**, אותו דבר
- ⚠️ **הבדיקה השנייה חשובה מהראשונה.** 401 שכותב שורה לפני שהוא דוחה הוא באג

## 2.4 · המחיר מה-DB

```
POST /payments/subscriptions/start  עם amount: 1  בגוף
ASSERT הסכום שנרשם == monthly_price_nis מ-subscription_plans
```

## 2.5 · `is_fake`

- כל שורה שהריצה יצרה → **`is_fake = TRUE`**
- `SELECT COUNT(*) WHERE is_fake = FALSE` → **0 בסטייג'ינג**

# §4 · 🔴 XSS — סבב הזרקה מלא, לא grep

**S1 בודק שהתוכן הזרוע נקי. הוא לא מזריק.** ההבדל מהותי: הוא מאמת את הזרע, לא את הסניטציה.

```
1  אדמין → PATCH /admin/legal/terms  עם body_md שמכיל:
       <script>alert(1)</script>
       <img src=x onerror=alert(1)>
       [קישור](javascript:alert(1))
       <iframe src="//evil"></iframe>
2  אנונימי → GET /legal/terms
3  ASSERT התשובה לא מכילה:  <script  ·  onerror=  ·  javascript:  ·  <iframe
4  🔴 החזר את התוכן המקורי
```

- **שמור את `body_md` המקורי לפני, ושחזר אחרי. גם אם הבדיקה נכשלת.** `try/finally`
- **אם השחזור נכשל — `exit 1` עם הודעה בולטת.** דף תנאי שימוש עם `<script>` שנשאר הוא גרוע בהרבה מבדיקה שנכשלה
- `version` יעלה ב-2 וייווצרו שתי שורות history — **זה תקין וצפוי. ציין בפלט**
