# §4 · "יש תוצאות" ו"לא נמצאו מודעות" באותו מסך

## הצילום

```
שירותים נלווים · תוצאה אחת     ← קורס עברית בסיסית, ₪950
לא נמצאו מודעות התואמות        ← בלוק ענבר על כל הרוחב
0 תוצאות                        ← בשורת החיפוש
```

## השורש

`app/page.tsx:1480-1482`

```tsx
const exact = resp.results.length;          // מודעות בלבד
const near  = resp.near_matches?.length ?? 0;
if (exact === 0 && near === 0) return 'לא נמצאו מודעות התואמות לחיפוש';
```

**ושורה 1597 — בלוק הענבר — נשען על אותו תנאי.**

> **`marketplace_matches` לא נספר באף אחד מהשניים.**
> **U6 §2 הוסיף מקטע תוצאות שני ולא עדכן את המונה ואת מצב-הריק.**

## Do

- **המונה סופר את שני המקטעים.** `1 תוצאה`, לא `0 תוצאות`
- 🔴 **בלוק "לא נמצאו" מרונדר רק כששלושתם ריקים** — `results`, `near_matches`, `marketplace_matches`
- **כשעובדים ריקים ושירותים לא — נוסח אחר, לא "לא נמצאו":**
  > `לא נמצאו עובדים או דיור לחיפוש הזה. מצאנו התאמה בשירותים הנלווים.`
  **ההודעה חייבת להסביר מה כן נמצא. "לא נמצא" ליד תוצאה גלויה קורא כמו תקלה**
- **צ׳יפ "עובדים" בשורת החיפוש** ⚠️ — בצילום הוא פעיל, כלומר הסינון חל על מודעות. **בדוק שהוא לא מסנן גם את השירותים הנלווים בלי כוונה. דווח**
